# تأكيد الديبوزيت من زر تليجرام

هذا السكربت يستبدل `doPost` الحالي في مشروع Apps Script المرتبط بشيت «طلبات كتاب تلوين البطل». الموقع يرسل الأوردر للسكربت؛ السكربت يكتبه في `Sheet1` ويرسل رسالة Jump Snap مع زر «تأكيد الديبوزيت». الضغط على الزر يطلب المبلغ، ثم يسجل المدفوع والباقي ووقت التأكيد في الصف نفسه. الباقي يقرب **لأعلى أقرب 10 جنيهات**.

## قبل نشر تعديل الموقع

1. افتح مشروع Apps Script المرتبط بالشيت. استبدل محتوى `Code.gs` بمحتوى الملف المرفق هنا.
2. افتح **Project Settings → Script Properties** وأضف:
   - `BOT_TOKEN`: مفتاح بوت Jump Snap الحالي. احتفظ به داخل إعدادات Apps Script فقط.
   - `ADMIN_CHAT_ID`: رقم حساب تليجرام الذي تصله الأوردرات.
3. شغّل `prepareOrdersSheet` مرة واحدة، ثم `installReplyPolling` مرة واحدة، ووافق على صلاحيات Google المطلوبة. إذا أخبرك السكربت أن للبوت webhook قائمًا، لا تحذفه؛ أوقف هذه الخطة وادمج معالج الرد في خدمة الـwebhook القائمة.
4. أعد نشر تطبيق الويب Apps Script من **Deploy → Manage deployments → Edit → New version**. استخدم نفس رابط `/exec` الموجود في `index.html`. شغّل التطبيق بصلاحيات مالك الشيت، واجعل الوصول متاحًا للزوار الذين يقدمون الطلبات.
5. بعد نشر السكربت، انشر تعديل `index.html` الموجود في هذا التغيير. لا تنشر تعديل الموقع قبل السكربت، لأن رسائل تليجرام الجديدة ستتوقف مؤقتًا.
6. أرسل طلبًا تجريبيًا، وتأكد من صف الشيت ورسالة تليجرام والزر. اضغط الزر واكتب مبلغًا تجريبيًا، وتحقق من عمودي «المبلغ المدفوع» و«الباقي».
7. مفتاح البوت القديم كان ظاهرًا في الصفحة العامة. بعد نجاح الاختبار، جدّد المفتاح من BotFather، وحدّث `BOT_TOKEN` في Script Properties، ثم اختبر مجددًا. لا تضع المفتاح الجديد في GitHub أو في الشيت.

## استخدام الزر

اضغط «💰 تأكيد الديبوزيت» تحت الأوردر. البوت يطلب رقمًا مثل `60`. رد على طلب البوت بهذا الرقم. إذا كان الإجمالي 359، يسجل المدفوع 60 والباقي 300. يرفض السكربت المبلغ الذي يتجاوز الإجمالي أو محاولة تأكيد أوردر مؤكد بالفعل.

الأوردرات القديمة بلا زر. ما زال ممكنًا الرد على رسالة الأوردر القديمة بصيغة `تم التأكيد 60`، بشرط أن يطابق الشيت صفًا واحدًا فقط. إذا تكرر نفس الأوردر في أكثر من صف، لا يغير السكربت شيئًا لتجنب تحديث صف خاطئ.

## ملاحظات تشغيلية

- فحص ردود تليجرام يتم بمشغّل Apps Script كل دقيقة؛ التحديث قد يتأخر نحو دقيقة.
- يجب أن يبقى مشروع Apps Script مرتبطًا بالشيت نفسه، وأن يكون التبويب المستهدف `Sheet1`.
- لا تشارك `BOT_TOKEN` مع أي شخص أو تضعه في ملف عام.
- إرسال النموذج من موقع GitHub Pages يستخدم `no-cors`، لذلك لا يستطيع المتصفح قراءة نجاح أو فشل السكربت. اختبر سجل تنفيذ Apps Script والأوردر التجريبي بعد النشر.
