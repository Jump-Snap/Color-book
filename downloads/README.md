# وصل لأندرويد — نسخة اختبار 0.4.0

القائمة العلوية أزيلت. افتح زر «القائمة — الربط والأذونات» الكبير أسفل التطبيق، داخل هوامش بعيدًا عن حواف الشاشة، لعرض أزرار التنقل في وسط الشاشة.

صفحة الأذونات تعرض الحالة الحالية وتقودك لطلب تنبيهات الطلبات، وقراءة إشعارات البريد، وقراءة Paid في واتساب بيزنس. الموافقة تتم منك في أندرويد. إذا ظهرت الإعدادات المقيّدة، ستجد شرحًا وزرًا لفتح معلومات التطبيق. التصوير واختيار الملفات يمران بتطبيقات النظام دون وصول عام للتخزين أو سجل SMS.
